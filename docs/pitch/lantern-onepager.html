What a reviewer sees

  • Every number traces. Each figure on screen carries its source, pull time and SHA-256; raw responses are kept on disk; notes regenerate bit-for-bit from the stored model run.
  • Honesty is enforced by architecture, not prompts. A filings answer ships only with quotes that are character-for-character verbatim in the filing, cited to the page — otherwise one fixed abstention sentence. A research-note draft that uses a number absent from the model run is rejected automatically.
  • The models keep their own public scorecard. An accuracy ledger scores every past forecast against what the market then did; the Q&A system is gated on abstention precision against a human-verified gold set; every claim below is reproducible from the repository.

On-premise by design

  • One environment variable swaps the cloud model for an open-weight model on the bank's own GPU — identical interface, verification, logging; the answer is labelled with its true source and model.
  • Judging is local too: the evaluation harness scores against a locally served judge, so model-risk evidence is producible inside the perimeter.
  • Data, documents, keys and model weights never leave the building; the demo runs from a laptop on live public data each morning.
  • Governance-ready: model inventory, prompt hashes, provenance, calibration disclosures and challenger comparisons map directly onto the MAS Guidelines on AI Risk Management (inventory expectations ~October 2027).
  • Third-party diligence done: every component and data source catalogued with its license; the two items needing commercial resolution (PDF library, market-data feed) are identified with costed paths.

Scale path: the whole Singapore market

  • 65 annual reports are live in Filings Q&A: all 30 Straits Times Index companies and 35 of the 36 SGX REITs and business trusts (the 36th, UI Boustead REIT, listed in March 2026 and has not yet published one). Each report is checked as a real PDF naming the right issuer, with its SHA-256 and source recorded. Expansion to every SGX-listed issuer is in progress: 98 reports verified so far, with coverage measured per batch.
  • Production deployment replaces web harvesting with the bank's licensed SGX/market-data entitlements — the pipeline from ingest onward is identical.
  • Index engineering for ~700k passages is scoped with performance gates (retrieval latency budget ~1s).

Why this, why now

  • Research output across Singapore banks is thin relative to the data available; no local bank publishes a calibrated valuation-risk metric on AI equities.
  • Lantern's answer is measurable outcomes: a number with a public track record, answers with verbatim evidence, and a note a reviewer can regenerate.
  • First working version built in under two weeks on public data; every subsequent module landed with tests, independent review and a signed scorecard.
